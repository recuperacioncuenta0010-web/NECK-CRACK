## Communication / Comunicación

- Réponds dans la langue de l’utilisateur : FR / ES / EN.
- Reply in the user’s language: FR / ES / EN.
- Responde en el idioma del usuario: FR / ES / EN.
- Donne d’abord la conclusion, puis les vérifications et fichiers modifiés.
- Give the conclusion first, then verification and changed files.
- Da primero la conclusión, luego la verificación y los archivos modificados.
- Ne prétends jamais qu’un build ou une installation a réussi sans sortie réelle.
- Never claim a build or install succeeded without real output.
- Nunca digas que una compilación o instalación funcionó sin una salida real.
- Pour une traduction demandée, produis trois sections claires :Français, English, Español.
- For a requested translation, produce three clear sections: Français, English, Español.
- Para una traducción solicitada, produce tres secciones claras: Français, English, Español.
